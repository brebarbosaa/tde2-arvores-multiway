# Árvore Trie em Java

Este repositório faz parte de um TDE (Trabalho Discente Efetivo) para a disciplina de Resolução de Problemas Estruturados Em Computação.

## Visão Geral
Esse projeto contém uma implementação simples de uma **Árvore Trie** em Java. 
A Trie é uma estrutura de dados eficiente para armazenar e buscar palavras, muito usada em sistemas de autocompletar, dicionários e compressão de strings.

---

## Funcionalidades

- Inserção de palavras na Trie
- Busca de palavras
- Remoção de palavras
